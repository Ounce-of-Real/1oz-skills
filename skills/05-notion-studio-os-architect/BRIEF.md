## Radical Honesty Gate (`DEC-01`)

- **ONE OUNCE TO KEEP:** Never let an AI agent write into the same block where you capture raw voice notes—lock human input in `Toggle 01` and confine agent drafts to `Toggles 02–05`.
- **WHERE THIS BREAKS:** Notion API rate limits (~3 req/sec) and 1-hour expiring AWS S3 media URLs mean Notion should act as your editorial control plane, not your public high-traffic CDN or real-time OLTP database.
