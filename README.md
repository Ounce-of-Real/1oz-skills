## The `DEC-01` & `DEC-02` Access Standard

1. **Zero-Friction Open Task Briefs (This Repository):**
   Every skill directory below includes an open **4-Field Task Brief (`BRIEF.md`)** (`Task`, `Input`, `Rules`, `Output`), a **Basis Stamp** (`PERSONAL TRIAL · N=1`, `PUBLISHED RESEARCH`, or `BUILD LOG`), **One Ounce to Keep**, and a mandatory **`WHERE THIS BREAKS:`** failure-mode disclosure. You can copy any open brief immediately without an account.

   Complete production `SKILL.md` agent packages (with multi-pass scoring matrices, banned-word lexicons, and system guardrails) unlock free via verified account sign-in on **[ounceofreal.com/skills](https://ounceofreal.com/skills)**.
